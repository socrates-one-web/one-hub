# Contribuir a ONE HUB

¡Gracias por tu interés en ONE HUB Community!

## Estado

La primera publicación de código abierto está pendiente de auditoría de seguridad y licencias. **Todavía no se solicitan contribuciones de código para producción.**

Cuando se publique el código y su licencia, podrán recibirse informes de errores, mejoras de documentación, traducciones (ES/PT-BR/EN), pruebas de instalación y propuestas de funcionalidades.

## Antes de abrir un Issue

1. Verifica que el problema no esté reportado.
2. Identifica la versión, entorno PHP/MySQL y pasos reproducibles.
3. Retira contraseñas, claves y datos de clientes de cualquier captura o registro.
4. Si es un problema de seguridad, utiliza las instrucciones de [SECURITY.md](SECURITY.md) y **no abras un Issue público**.

## Diseño de las contribuciones

Se priorizarán cambios pequeños, reproducibles, accesibles, compatibles con dispositivos móviles y traducidos a español, portugués e inglés.
