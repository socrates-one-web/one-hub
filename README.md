# ONE HUB Community

**Plataforma de gestión empresarial · Próximamente Open Source**

[Web oficial](https://os.socrates.la/) · [Documentación de instalación](https://os.socrates.la/manual.php)

ONE HUB reúne en un mismo ecosistema la gestión de clientes, ventas, cotizaciones, contratos, proyectos, documentos, finanzas, informes y **EMAILSEND** (campañas de correo electrónico).

## Estado de publicación

**PRE-LANZAMIENTO — Licencia del código propio definida; publicación de código pendiente de auditoría técnica y dependencias.**

El software ya dispone de instalaciones de prueba CLEAN y DEMO, pero **el código fuente y los paquetes públicos todavía no están disponibles en este repositorio**. No uses las versiones de prueba como distribución pública hasta terminar la revisión de seguridad y derechos de terceros.

### Funcionalidades

- CRM, contactos, oportunidades y pipeline comercial
- Cotizaciones multimoneda y contratos
- Proyectos, tareas, calendario, horas y riesgos
- Gestión documental, versiones y permisos
- Finanzas, cobranzas, tableros e informes
- EMAILSEND: contactos, listas, campañas y métricas
- Interfaz en español, português (Brasil) e inglés

### Ediciones previstas

| Edición | Descripción |
| --- | --- |
| **CLEAN** | Instalación sin datos empresariales |
| **DEMO** | Instalación con información ficticia para evaluación |

Las dos ediciones se distribuirán gratuitamente una vez completados los controles de publicación. Las demos deben mantenerse sin capacidad de envío a direcciones reales.

### Requisitos previstos

- PHP 8.1 o superior
- MySQL y extensión PDO MySQL
- OpenSSL, Fileinfo y mbstring
- Servidor web configurado para PHP
