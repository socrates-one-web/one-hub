# SÓCRATES ONE CRM + PROJECT MANAGER · DEMO COMPLETA

Este paquete mantiene el núcleo 1.9.0 y agrega un cargador de datos ficticios para presentaciones.

## Instalación nueva
1. Cree una base MySQL vacía y un usuario con todos los privilegios.
2. Suba el contenido de `socrates-one-crm` al subdominio.
3. Abra `install.php`.
4. Marque **INSTALAR CONTENIDO DEMO COMPLETO**.
5. Complete la instalación y luego elimine o bloquee `install.php`.

## Si ya instaló el sistema
Suba `includes/demo_seed.php` y `demo_data.php`, inicie sesión como administrador y abra `demo_data.php`.
